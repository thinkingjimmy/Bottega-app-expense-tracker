# 💰 记账本

## 这个 App 做什么

用一句话记账。你在使用 chat 里说「午餐 25」「昨天打车 38」，Agent 就把它写成账本里的一行：日期、金额、分类、备注四列齐全。明细页看流水，分析页看分类占比与每日趋势。

## 怎么用

1. 安装后先查看 6 行示例数据。
2. 开始记自己的账之前，删除 `sample-*` 示例行。
3. 在使用 chat 中描述开销、改账或统计问题。
4. 切到「分析」页看分类占比和每日支出。

内置七类：餐饮、交通、购物、居住、医疗、娱乐、其他。退款、报销到账以负数记录并在备注中说明。

## 依赖

无。App 只使用 AI Chat 内置 Base 工具。
